== Versal JTAG Selector (JP13-JP18)
JP13-JP18 are interfaces capable of switching the connection destination of the Versal FPGA JTAG interface. +
When jumper sockets are inserted between Pin.1-2, it connects to Channel A of the FTDI IC, enabling access from CON6 (USB Type-C). +
By inserting them between Pin.2-3, it becomes possible to communicate with the FMC module connected to CON11 via level shifters (IC22, IC23).

[NOTE]
====
Jumper sockets are inserted between Pin.1-2 by default, and since it is a 2 x 6 size, 6 pins can be switched at a time.
====

== Versal APU/RPU Console (UART0) Selector (JP19-JP21)
JP19-JP21 are interfaces capable of switching the connection destination to Channel B of the FTDI IC. +
When jumper sockets are inserted between Pin.1-2, it connects to UART0 mapped to the Versal LPD MIO. +
By inserting them between Pin.2-3, it connects to UART0 (EMIO) mapped to the Versal HDIO. +
After connection, access is possible from CON6 (USB Type-C).

[NOTE]
====
Jumper sockets are inserted between Pin.1-2 by default, and since it is a 2 x 3 size, 3 pins can be switched at a time.
====

== IGLOO2 Telemetry/Telecommand Selector (JP25-JP29)
JP25-JP29 are interfaces capable of switching the connection destination of the IGLOO2 UART. +
By accessing the IGLOO2 UART, it is possible to monitor via Telemetry signals from the OBC or change modes via Telecommand signals to the OBC. +
When jumper sockets are inserted between Pin.1-2, it connects to Channel D of the FTDI IC, enabling access from CON6 (USB Type-C). +
By inserting them between Pin.2-3, access becomes possible from CON18 using devices compatible with the RS-422/RS-485 standard.

[NOTE]
====
Jumper sockets are inserted between Pin.1-2 by default, and since it is a 2 x 5 size, 5 pins can be switched at a time.
====

== RS-422/RS-485 Communication Setting Selector (JP30-JP33)
JP30-JP33 are interfaces to configure when connecting RS-422/RS-485 compatible devices to CON18 to communicate with the OBC. +
Please set the jumper sockets according to the corresponding device by referring to the table below.

[NOTE]
====
By default, a jumper socket is inserted in JP31.
====

image::JP30.webp[Detail Image of JP30 to JP33]

[width="100%",cols="1,7",options="header",]
|===
|REF |Description
|JP30 |Interface to select the presence of a Driver termination resistor. +
Please insert a jumper socket if terminating the Driver.
|JP31 |Interface to select the presence of a Receiver termination resistor. +
Please insert a jumper socket if terminating the Receiver.
|JP32 |Interface capable of short-circuiting the Y and A terminals of the Transceiver. +
Please insert a jumper socket when communicating in half-duplex.
|JP33 |Interface capable of short-circuiting the Z and B terminals of the Transceiver. +
Please insert a jumper socket when communicating in half-duplex.
|===

[NOTE]
====
When terminating in half-duplex communication, please insert a jumper socket into either JP30 or JP31.
====

== Versal GTYP Selector (JP34)
JP34 is an interface capable of switching the connection destination of GTYP, which is Versal's high-speed serial communication signal. +
Please insert a jumper socket if you wish to perform high-speed debugging and tracing of Versal using a SmartLynq+ module utilizing CON6 (USB Type-C). +
If you do not perform the above and wish to evaluate the target GTYP with the FMC module connected to CON11, do not insert a jumper socket.

== Versal I2C Selector (JP35-JP37)
JP35-JP37 are interfaces used when you want to utilize the Versal LPD MIO mapped to I2C0 with the FMC module. +
Please insert jumper sockets if you want to use it with the FMC module. +
The Versal LPD MIO will be connected to the FMC module connected to CON11 via a level shifter (IC24).

[NOTE]
====
By default, 2 x 3 size jumper sockets are inserted into JP35-JP37.
====

[CAUTION]
====
The target Versal LPD MIO is also routed to CON12.
====

== Versal MIO Communication Direction Selector (JP47-JP48)
JP47-JP48 are interfaces configured according to the communication direction of Versal PMC MIO 0 and Versal PMC MIO 1 connected to CON12. +
Because the target MIO passes through a level shifter (IC27) on its way to CON12, it is necessary to set the communication direction of the level shifter according to the MIO's communication direction. +
The table below shows the input/output directions as seen from CON12 when a jumper socket is inserted or removed.

[NOTE]
====
By default, no jumper sockets are inserted.
====

== FMC Module I/O Voltage Selector (JP57-JP58)
JP57-JP58 are interfaces that allow selecting the power domain of the Versal XPIO and IGLOO2 MSIO (Bank 8) connected to the FMC module. +
Since it is similarly supplied to the VADJ terminal of CON11, communication becomes possible at the selected power domain here.

[NOTE]
====
By default, a jumper socket is inserted into JP58.
====

[CAUTION]
====
Inserting jumper sockets into both JP57 and JP58 will result in an unintended voltage. +
Unlike other power selectors, because the voltage is changed by altering the Feedback resistor of the Switching Regulator.
====

|JP58 |1.5V
