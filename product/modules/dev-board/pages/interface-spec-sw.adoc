== Versal Boot Mode Control Switch (SW1)
SW1 is a DIP switch for controlling the Versal boot mode.

[width="100%",cols="1,1,1,1,1",options="header",]
|===
|Mode |Pin Number |Pin Name |I/O |Power Domain
|MODE 0 |1, 8 |XCVE_MODE0 |Input |Power supply (VDD_5V0_CM)
|MODE 1 |2, 7 |XCVE_MODE1 |Input |Power supply (VDD_5V0_CM)
|MODE 2 |3, 6 |XCVE_MODE2 |Input |Power supply (VDD_5V0_CM)
|MODE 3 |4, 5 |XCVE_MODE3 |Input |Power supply (VDD_5V0_CM)
|===

Depending on the switch configuration, it is possible to set the boot mode as follows.

== Versal POR Control Switch (SW2)
SW2 is a tactile switch capable of controlling the Versal External POR (Power On Reset). +

[CAUTION]
====
Please do not use this switch, as it is intended for factory use only.
====

== IGLOO2 POR Control Switch (SW3)
SW3 is a tactile switch capable of controlling the IGLOO2 POR (Power On Reset). +

[CAUTION]
====
Please do not use this switch, as it is intended for factory use only.
====

== Dev Board Main Power Switch (SW4)
SW4 is a slide switch capable of toggling the Dev Board main power ON/OFF. +
By moving the toggle toward the "ON" silkscreen side, main power is supplied to the circuit.
When set to the "OFF" silkscreen side, main power is disconnected.
